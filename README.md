# Straßenbau-Trainer

Kostenlose Lern-App für die **Zwischenprüfung Straßenbauer/in**: Lernkarten, Quiz, Rechenübungen mit Lösungsweg, Prüfungssimulation mit Zeitlimit, Fehlertraining und Notizen.

- Läuft im Browser auf Handy und Computer, ohne Anmeldung
- Der Lernfortschritt bleibt nur auf deinem Gerät (im Browser gespeichert)
- Funktioniert nach dem ersten Öffnen auch offline. Auf dem Handy: „Zum Home-Bildschirm hinzufügen“

**Hinweis:** Das ist allgemeines Übungsmaterial und keine offizielle Prüfungsaufgabensammlung. Maßgeblich sind die Unterlagen aus Betrieb, Berufsschule und überbetrieblicher Ausbildung.
